# Independent review and coordinator checks

Two bounded read-only code reviews covered the numerical path and build/evidence workflow. A Hermes MCP review also ran on explicitly selected inline patch/evidence text. The bridge could not accept this workspace as a working root, so no workspace files were forwarded implicitly. Hermes's actual runtime model ID was not exposed; the owner's reported default DeepSeek 1017 checkpoint is not independently verified here. Review outputs are reasoning, not hardware measurements.

Confirmed findings and changes:

- **Pre-existing quantized K-tail overwrite risk.** Activation quantizers emit full 128-byte halves, but some K lengths have smaller allocated row strides. The host now declines quantized dense and indexed multiplies whose K is not divisible by 128. This is conservative containment, preserving tested TTS dimensions. Unsafe shapes are checked by metadata queries only, without executing them. Five quantized types across K32/64/96/128/256/288/384 and both operator forms give 70 support checks; supported K256/384 also receive actual Q8 oracle checks.
- **Ambiguous speech-code provenance after late failures.** A failed decode or WAV save can leave a dump even though the response is unsuccessful. The benchmark now associates dumps only when a fresh exclusive directory contains exactly the expected contiguous files for successful responses. Otherwise it records ambiguity and refuses all associations; raw files and request errors remain available. Existing published request mappings are unaffected because their failures preceded code dumping. Coordinator checks covered success, early failure, late failure, gapped filenames and empty failure cases.
- **Partial private runtime cleanup.** A matching extraction stamp did not guarantee that x86 library files still existed. Preparation now re-extracts the verified small Debian runtime packages on each pass. A moved-aside libatomic runtime file was restored byte-for-byte from its pinned package.
- **Quantizer scope clarified.** The large-value fallback requires that amax/127 remain representable by the existing FP16 scale format. It does not claim support for all finite FP32 magnitudes. The tested default group size is 128; group32/64 remain validation gaps.

Other concerns were checked against implementation rather than adopted as facts. The max helper performs a full horizontal reduction and the caller supplies aligned, zero-padded temporary storage. Group sizes are compile-time choices 32/64/128. Exact Q8 roundtrip refers to immutable canonical weight upload/readback, not activation quantization or model parity. The oracle's finite, normalized-error and cosine gates prevent an all-zero answer from passing a nonzero-reference matrix case.

The unresolved 1.7B CPU/OpenCL prefill failures are separate from the isolated HTP FFN old/new replay. CPU and OpenCL controls execute their own operator implementations. No causal claim about their failure, or speedup claim from failed controls, is made. Later predictor heads are checked for finiteness; teacher-forced all-head parity and listening remain open.
